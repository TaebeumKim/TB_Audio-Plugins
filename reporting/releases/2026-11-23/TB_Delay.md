# TB Delay 1.2.0

## [1.2.0] - 2026-11-23

로그 범위 파라미터 6개의 호스트 표시를 소수 7자리에서 고정 자릿수로 바꿔 Low Cut 입력값 왕복 오차를 없애고, 화면을 TB 공통 시각 언어로 바꿨습니다.

- Windows x64 VST3 ZIP와 설치 파일을 갱신했습니다. 카탈로그 가격과 기존 macOS 다운로드는 유지합니다.
- 기존 CID·파라미터 ID·상태·프리셋 계약을 유지합니다.
- Release 빌드, 제품 하니스, Host 계약(이전 공개본과 비교)을 통과했습니다.
- 실제 DAW 청취·수동 GUI/DPI 확인·설치 실행·서명 검증은 미실행입니다.

## Known boundary

Delay Time·Low Cut·High Cut·Mod Rate·Size·Grain Size의 호스트 표시 문자열만 바뀌었습니다(예: `375.0000305 ms` → `375.0 ms`). 값·ID·상태는 유지됩니다.
