# TB Resonator 1.1.0

## [1.1.0] - 2026-11-23

모드 디스플레이가 엔진이 실제로 쓰는 8개 모드(주파수·무게·T60)를 그리도록 바꾸고 화면을 TUNE 중심의 TB 공통 시각 언어로 바꿨습니다. 소리는 바뀌지 않았습니다.

- Windows x64 VST3 ZIP와 설치 파일을 갱신했습니다. 카탈로그 가격과 기존 macOS 다운로드는 유지합니다.
- 기존 CID·파라미터 ID·상태·프리셋 계약을 유지합니다.
- Release 빌드, 제품 하니스, Host 계약(이전 공개본과 비교)을 통과했습니다.
- 실제 DAW 청취·수동 GUI/DPI 확인·설치 실행·서명 검증은 미실행입니다.

## Known boundary

모드 계산을 엔진과 화면이 함께 쓰도록 옮긴 것이라 소리는 같습니다. 파라미터·상태·프리셋은 유지됩니다.
