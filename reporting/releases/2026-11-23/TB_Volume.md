# TB Volume 1.3.0

## [1.3.0] - 2026-11-23

- BrickwallLimiterTests, VolumeMappingTests, UI 캡처, Host 계약 및 네이티브 UI attach/paint/remove 검사를 통과했습니다.
- 실제 DAW 청취·수동 GUI/DPI 확인·설치 실행·서명 검증은 미실행입니다.
