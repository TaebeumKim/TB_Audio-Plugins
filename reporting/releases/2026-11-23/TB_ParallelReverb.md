# TB Parallel Reverb 3.3.0

## [3.3.0] - 2026-11-23

페달보드 화면을 엔진 패널 세 장과 MASTER 띠의 TB 공통 시각 언어로 바꾸고 기본 창을 900 × 620으로 키웠습니다. DSP와 프리셋은 그대로입니다.

- Windows x64 VST3 ZIP와 설치 파일을 갱신했습니다. 카탈로그 가격과 기존 macOS 다운로드는 유지합니다.
- 기존 CID·파라미터 ID·상태·프리셋 계약을 유지합니다.
- Release 빌드, 제품 하니스, Host 계약(이전 공개본과 비교)을 통과했습니다.
- 실제 DAW 청취·수동 GUI/DPI 확인·설치 실행·서명 검증은 미실행입니다.

## Known boundary

기본 창 크기가 600 × 520에서 900 × 620으로 커졌습니다. DSP·파라미터·프리셋은 바뀌지 않았습니다.
