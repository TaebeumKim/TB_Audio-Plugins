# TB Pitch Shifter 3.0.1

## [3.0.1] - 2026-11-23

헤더 로고의 불투명도를 수정했습니다.

- Windows x64 VST3 ZIP와 설치 파일을 갱신했습니다. 카탈로그 가격과 기존 macOS 다운로드는 유지합니다.
- 기존 CID·파라미터 ID·상태·프리셋 계약을 유지합니다.
- Release 빌드, 제품 하니스, Host 계약, 네이티브 UI 종료 검사를 통과했습니다.
- 실제 DAW 청취·수동 GUI/DPI 확인·설치 실행·서명 검증은 미실행입니다.

## Known boundary

헤더 로고 불투명도만 수정했으며 DSP·파라미터·상태·프리셋은 변경하지 않았습니다.
