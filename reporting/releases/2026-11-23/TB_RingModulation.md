# TB Ring Modulation 1.1.0

## [1.1.0] - 2026-11-23

Square·Triangle 캐리어의 앨리어싱(−15.7 dB → −131 dB)과 초저역 캐리어 주파수 오차를 고치고 화면을 TB 공통 시각 언어로 바꿨습니다.

- Windows x64 VST3 ZIP와 설치 파일을 갱신했습니다. 카탈로그 가격과 기존 macOS 다운로드는 유지합니다.
- 기존 CID·파라미터 ID·상태·프리셋 계약을 유지합니다.
- Release 빌드, 제품 하니스, Host 계약(이전 공개본과 비교)을 통과했습니다.
- 실제 DAW 청취·수동 GUI/DPI 확인·설치 실행·서명 검증은 미실행입니다.

## Known boundary

Square·Triangle 캐리어가 대역 제한되어 고역의 접힌 성분이 사라집니다. 이전 버전의 거친 고역에 맞춘 세션은 소리가 달라질 수 있습니다.
