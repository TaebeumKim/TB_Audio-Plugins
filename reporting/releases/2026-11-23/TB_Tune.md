# TB Tune 2.2.0

## [2.2.0] - 2026-11-23

호스트 bypass 전환 시 일반 모드와 Live Tone 모드의 지연·tail 보고를 정렬하고, Live Tone 저지연 모드와 음성 반응형 컬러 워시를 반영했습니다.

- Windows x64 VST3 ZIP와 설치 파일을 갱신했습니다. 가격은 기존 1을 유지합니다.
- 기존 CID와 기존 Key/Auto Musical/Scale/Formant Shift/Bypass 파라미터 ID·메타데이터·상태 호환성을 유지했습니다. 새 기능으로 Low Latency Tone과 프로그램 슬롯이 추가됩니다.
- AutoTuneHarness, UIHarness, Host 계약 및 네이티브 UI attach/paint/remove 검사를 통과했습니다.
- 실제 DAW 청취·수동 GUI/DPI 확인·설치 실행·서명 검증은 미실행입니다.
