# TB Delay 1.2.1

## [1.2.1] - 2026-11-26

호스트 bypass 복귀 뒤 옛 echo가 다시 재생되지 않도록 엔진을 비우고, 실제 echo·grain·BLUR·SHIFT·WOBBLE 경로를 반영해 −60 dB tail 보고를 보정했습니다.

- 기존 40개 파라미터 ID, CID, 상태·프리셋 계약을 유지했습니다. 가격은 기존 3을 유지합니다.
- Delay 테스트 `pass=39 fail=0 skip=0`, Host contract, 네이티브 UI 검사를 통과했습니다.
- 실제 DAW 청취·설치 실행·서명 검증은 미실행입니다.
