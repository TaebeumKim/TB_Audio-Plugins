## 0. 사용자가 제공한 컨셉 (원문 그대로)

```text
JUCE SDK를 이용해서 익사이터 만들고 싶어.
상위에 Guide md폴더있으니까 읽고 시작하고.
목표는 소프트튜브의 바이스 익사이터
그리고 웨이브즈의 아팩스 익사이터 정도야.
세츄레이션이 필요하면 추가하고 고역대를 밝게 만들어주는게 목표야.
```

레퍼런스 식별:

- `소프트튜브의 바이스 익사이터` = **Softube / Weiss Exciter** (Weiss Engineering 협업, 마스터링용 투명 익사이터)
- `웨이브즈의 아팩스 익사이터` = **Waves Aphex Vintage Aural Exciter** (Aphex Aural Exciter 하드웨어 복각)

두 레퍼런스는 성격이 정반대에 가깝다. 초기 탐색에서는 투명한 마스터링 방향과 빈티지한
트랜지언트 방향을 함께 검토했지만, 최종 후보는 **공진 보호 셸프 중심, 배음 보조**의 투명한
방향을 택한다. 목표는 배음층이 별도 distortion으로 인식되지 않고 좁은 공진은 과도하게
커지지 않으면서 상단이 열리는 것이다.

Softube / Weiss와 Waves / Aphex라는 이름은 청감·UX 비교의 영감만 가리킨다. TB_Exciter는
어느 제품의 알고리즘도 추정·복제하지 않으며 동일한 결과나 동등성을 주장하지 않는다
(`TB_PLUGIN_DEVELOPMENT_GUIDE.md` 3.5).

## 1. 컨셉 브리프

### 1.1 제품 기본 정보

```text
프로젝트명: TB_Exciter
제품 표시명: TB_EXCITER
한 문장 정의: BRIGHT로 공진을 보호한 상단 셸프 성분을 중심으로 더하고 낮은 해석신호 배음을
              보조해, distortion으로 인식되지 않는 밝기와 공간감을 만드는 익사이터.
플러그인 종류: Harmonic Exciter / Enhancer (셸프 delta + 배음 생성 + 병렬 합성)
아날로그 복각 여부: 아니오
복각 대상(해당 시): 해당 없음. 두 제품 모두 비교 청취와 UX의 영감으로만 참고
주요 대상 사용자: 믹스·마스터링 엔지니어, 보컬/버스 작업자
주요 대상 소스: 풀믹스·버스, 보컬, 어쿠스틱 악기
대표 사용 상황: 믹스가 답답하거나 상단이 닫혔을 때, 투명한 셸프로 먼저 열고 낮은 배음
                보조로 미세한 정보감과 폭을 더한다.
```

### 1.2 해결하려는 음악적 문제

```text
사용자가 현재 겪는 문제:
  고역이 답답한 소스를 EQ 하이셸프로 올리면 이미 있는 노이즈, 시빌런스, 심벌의 거친
  성분까지 같이 커진다. 없는 정보를 EQ로 만들 수는 없다.

기존 작업 방식의 불편함:
  - 하이셸프: 있는 것만 키운다. 히스와 치찰음이 함께 올라간다.
  - 일반 새추레이터: 전대역에 배음을 걸어 저역이 뭉치고 원음의 밸런스가 바뀐다.
  - 기존 익사이터: 원음 대역과 처리 대역이 겹쳐 위상 간섭과 fizz가 생기기 쉽다.

이 플러그인이 만드는 결과:
  100 % 지연 정렬 드라이는 그대로 두고, 3×FOCUS(상한 9 kHz) 셸프 delta와 FOCUS–2×FOCUS를 재료로 한
  저레벨 배음을 added 경로로 합성한다. 고정 8대역 detector가 주변보다 좁게 솟은 성분을 찾으면
  해당 셸프 delta만 최대 25 % 완화한다. 밝기는 셸프가 주도하고 배음은 보조한다.

처리 전 상태: 상단이 닫혀 있고 디테일이 마스킹된 상태. 크게 틀어야 들리는 소리.
처리 후 기대 상태: 지각 음량의 변화가 작고 distortion 층은 들리지 않지만, 자음·브러시·손끝과
                   잔향 꼬리가 조금 더 잘 읽히는 상태.
```

### 1.3 제품 가치와 차별점

```text
이 플러그인을 선택할 한 문장 이유:
  단순 EQ보다 음악적인 상단을 빠르게 만들고, 따뜻함↔맑음과 추가 성분의 폭을 한 화면에서
  조절하는 익사이터.

일반적인 동종 처리와 다른 점:
  1. BRIGHT는 3×FOCUS(상한 9 kHz) 코너의 최대 +6.5 dB 하이셸프를 드라이에 직접 거는 대신
     `shelf(delayedDry) - delayedDry` delta로 분리해 added 경로에 넣는다.
  2. 지연 정렬 dry를 분석하는 고정 8대역 detector가 좁은 공진을 찾으면 그 대역의 셸프 delta
     상승만 최대 25 % 완화한다. 마지막 16.97 kHz 대역도 로그 주파수 외삽 기준선으로 보호한다.
     공진도 계속 양의 방향으로 증가하며 추가 레이턴시는 없다.
  3. 같은 added 경로에 adaptive 해석신호 `Re(z²)`·`Re(z³)` 배음을 보조로 더한다.
     `generatorDrive = 0.84`, `wetScale = 0.36`을 사용하며 이전 생성기보다 약 20 dB 낮다.
  4. CLARITY는 낮은 레벨의 2차 중심 ↔ 3차 중심 배합만 연속 모프한다.
  5. WIDTH는 드라이 정위를 바꾸지 않고 added 경로의 Side만 0–200 %로 조절한다.

기존 TB 플러그인과 겹치지 않는 점:
  - `TB_Distortion`: 전대역 드라이브와 TB 변조가 목적. 원음을 바꾼다. 이 제품은 원음을
    지연 정렬한 뒤 상단 added 경로를 병렬 합성한다.
  - `TB_EQ`: 선형 대역 조절이 중심이다. 이 제품은 셸프 delta에 낮은 adaptive 배음과
    added 전용 폭 제어를 결합한다.
  - `TB_SpectralTransientShaper`: 어택/서스테인의 레벨을 바꾼다. 이 제품은 별도 트랜지언트
    축 없이 상단 added 경로를 만든다.
  - `TB_SubLow`: 저역 생성 담당. 이 제품은 고역 전용이며 저역에 개입하지 않는다.

이 플러그인만의 컬러링 축:
  `CLARITY` — WARM ↔ CLEAR. **해석신호 주파수 배가**의 차수 배합만 바꾼다.
  0 %: 2배(Re z²) 우세 → 조금 더 둥글고 두꺼운 배음 보조.
  100 %: 3배(Re z³) 우세 → 조금 더 얇고 맑은 배음 보조.

  해석신호 배가는 일반 메모리리스 웨이브셰이핑보다 차음·자기변조를 줄이는 배음 보조
  경로다. 현재 제품의 밝기 대부분은 셸프 delta가 담당하며, 배음 경로는 그보다 충분히 낮아
  독립적인 distortion 층으로 들리지 않아야 한다.

의도적으로 하지 않을 것:
  - 저역 강화(Aphex Big Bottom류)를 v1에 넣지 않는다. 사용자의 목표는 고역이다.
  - 멀티밴드 크로스오버 UI와 애널라이저를 v1 핵심 범위에 넣지 않는다.
  - 리미터를 내장하지 않는다. 강한 BRIGHT·WIDTH·LEVEL 조합은 사용자가 헤드룸을 확인한다.
```

### 1.4 청감 A/B 성공 기준

```text
A 상태: TB_Exciter 인서트 기본값 (FOCUS 3.0 kHz / BRIGHT 40% / CLARITY 45% /
        WIDTH 130% / LEVEL 0 dB)
B 상태: 플러그인 바이패스
비교할 대상 또는 바이패스:
  1) 바이패스
  2) 같은 지각 음량으로 맞춘 하이셸프 EQ (+3 dB @ 6 kHz)
음량 매칭 방법: 지연 보상 후 두 출력의 통합 LUFS를 ±0.3 LU 이내로 맞춘다. Harness는
                소재의 실제 44.1/48 kHz 샘플레이트에 맞는 K-weighting을 사용한다.

반드시 구분되어야 할 청감 차이:
  - 하이셸프 대조군 대비: 차이는 미세해도 좋지만 added 전용 폭과 낮은 배음 보조 때문에
    상단의 정보감·공간감이 달라야 한다. 별도 distortion 층으로 들리면 실패다.
  - CLARITY 0% vs 100%: 같은 음량에서 2차 중심의 둥근 보조 vs 3차 중심의 맑은 보조.
  - WIDTH 0% vs 200%: 드라이 정위는 유지되고 더해진 상단의 폭만 달라진다.

차이를 표현할 음악적 단어: 공기, 선명도, 앞으로 나옴, 윤곽, 광택, 두께, 호흡
검증할 최소 소스 1: BUS_01_fullmix
검증할 최소 소스 2: VOX_01_female
실패로 판정할 상태:
  - 레벨 매칭 후 배음이 새추레이션·왜곡·fizz처럼 별도 층으로 인식된다.
  - 하이셸프 대조군보다 배음이 앞서 들리거나 CLARITY가 밝기보다 왜곡량을 바꾼다.
  - DRM_01에서 심벌이 fizz·aliasing으로 거칠어진다.
  - 기본값 또는 실용 범위에서 예기치 않은 피크 상승·클리핑이 발생한다.
```

### 1.5 청감 A/B 사용 소재

`Guide MD/Assets/README.md` 2절 규칙에 따라 3개만 사용한다. **한 번 고른 소재는 버전이
올라가도 바꾸지 않는다.**

| 역할 | 소재 | 선택 이유 |
| --- | --- | --- |
| 주 타깃 | `BUS_01_fullmix` | 마스터·버스에서 상단을 여는 것이 대표 사용처. 이미 밀도가 높아 잘못 만들면 즉시 지저분해지므로 제품 성패가 바로 드러난다. |
| 대조 | `VOX_01_female` | 자음·숨소리라는 완전히 다른 시간 구조. 낮은 adaptive 배음의 균일성과 시빌런스 악화 여부를 판정한다. |
| 역방향 검증 | `DRM_01_loop` | 심벌·하이햇에 이미 고역 에너지가 많아 익사이터를 **쓰면 안 되는** 대표 소재. fizz와 aliasing이 가장 먼저 드러나므로 쓸 만한 설정의 상한을 잡는다. |

메커니즘 검증에는 `Guide MD/Tools/TestSignals/`의 `01_sine_220`(배음 차수 측정),
`09_sweep_20_to_20k`(주파수 응답·앨리어싱), `08_pink_stereo`(무음/정상상태 안전성)를 사용한다.

### 1.6 기능 범위

#### 필수 기능

```text
- FOCUS–2×FOCUS 1옥타브 여기 대역 추출
- 3×FOCUS(상한 9 kHz) 코너의 최대 +6.5 dB 하이셸프 delta + 해석신호 배음 보조
- CLARITY(WARM↔CLEAR) 연속 모프 배음 구조
- `generatorDrive = 0.84`, `wetScale = 0.36`의 낮은 adaptive `Re(z²/z³)` 배음
- WIDTH 0–200 % added 전용 M/S 폭 제어
- 오버샘플링 기반 앨리어싱 억제 + 레이턴시 보정
- APVTS 전체 상태 저장/복원
- 호스트 bypass에서도 보고 레이턴시를 유지하고 DSP 상태를 계속 진행
- Standalone / VST3 (Windows x64)
```

플러그인 UI의 Undo/Redo 진입점. Factory 프리셋 선택기는 구현되어 있다.

#### 있으면 좋은 기능

```text
- 저역 강화(Big Bottom류) 모듈
- 배음 스펙트럼 애널라이저
```

핵심 효과와 완료 기준이 모두 통과한 뒤에만 검토한다.

#### 제외 범위

```text
- 멀티밴드 크로스오버 UI
- 디에서, 컴프레서 등 별도 다이내믹스
```

### 1.7 컨트롤 계획

| 공개 컨트롤 | Source Parameter ID | 사용자에게 들리는 역할 | 범위·단위 | 기본값 | 외부 제어 | 위계 | 필수 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| BRIGHT | `amount` | 셸프 delta와 배음 보조를 포함한 상단 added 양 | 0 – 100 % | 40 % | Host | Primary | 필수 |
| CLARITY | `character` | 낮은 배음의 2차 중심 ↔ 3차 중심 배합 | 0 – 100 % | 45 % | Host | Primary | 필수 |
| FOCUS | `tune` | 어느 1옥타브를 재료로 상단을 만들지 | 500 – 6000 Hz (log) | 3000 Hz | Host | Primary | 필수 |
| WIDTH | `width` | added 경로의 Side 폭 | 0 – 200 % | 130 % | Host | Standard | 필수 |
| LEVEL | `output` | 최종 출력 트림 | -12 – +12 dB | 0 dB | Host | Standard | 필수 |

- 공개 파라미터는 정확히 위 5개다. 표시명과 Source ID를 분리하며, ID는 호환 계약이다.
- 별도 트랜지언트 강도나 숨은 컬러 축은 두지 않는다.
- 오버샘플링 배수, adaptive 엔벌로프 시간 상수, 셸프 최대 게인, 스테레오 링크는 노출하지 않는다.
- 지연 정렬 드라이는 100 %로 고정하고 BRIGHT가 added 양만 제어하므로 별도 MIX를 두지 않는다.

#### 기본값 근거 (`TB_PLUGIN_DEVELOPMENT_GUIDE.md` 6.3)

| 파라미터 | 기본값 | 이 값으로 정한 이유 |
| --- | --- | --- |
| `amount` | 40 % | 셸프 delta가 먼저 들리고 해석신호 배음이 보조하는 실용 시작점. |
| `character` | 45 % | 2차 중심의 둥근 보조와 3차 중심의 맑은 보조 사이의 중간값. |
| `tune` | 3000 Hz | 3–6 kHz를 재료로 6 kHz 이상 상단을 여는 일반적인 버스 시작점. |
| `width` | 130 % | 원본보다 약간 넓지만 극단적인 Side 확대는 피하는 시작점. |
| `output` | 0 dB | 보정용 최종 트림. 기본값은 임의의 출력 게인을 더하지 않는다. |

#### 기본값 첫인상의 실측 근거

최종 투명화 후보의 기본값(BRIGHT 40 %) 실제 소재 측정은 다음과 같다. 테스트 개수는 문서에
고정하지 않고 최종 빌드의 최신 Harness 출력으로 확인한다.

| 소재 | 6–16 kHz Δ | 통합 LUFS Δ | Peak Δ |
| --- | ---: | ---: | ---: |
| `BUS_01_fullmix` | +0.60 dB | +0.02 LU | +0.29 dB |
| `VOX_01_female` | +1.02 dB | +0.09 LU | +0.02 dB |
| `DRM_01_loop` | +0.70 dB | +0.04 LU | +0.76 dB |

이 수치는 아래 조건과 함께 최종 Release Harness에서 판정한다.

- BRIGHT 0 %에서 출력은 보고 레이턴시만큼 지연된 드라이와 샘플 단위로 같아야 한다.
- 기본값과 실용 범위에서 피크·LUFS·6–16 kHz 변화가 과도하지 않아야 한다.
- dominant harmonic은 기본값에서 약 -34 dBc, 최대 BRIGHT에서 약 -22 dBc다(FOCUS 800 Hz 이하 기준.
  FOCUS 3 kHz 이상에서는 배음 틸트로 최대 약 +9 dB 더 높다).
- 최신 Release Harness의 앨리어싱은 -104.99 dBFS, CLARITY 양 끝 IMD는 -64.5 / -60.0 dB다.
- WIDTH는 added 경로의 Side만 바꾸고 Mid와 모노 출력은 실질적으로 유지해야 한다.
- CLARITY 양 끝은 짝수/홀수 구성이 달라야 하며 단순 볼륨 차이로 들리면 안 된다.
- 최대 BRIGHT·WIDTH·LEVEL 조합은 리미터가 없으므로 0 dBFS를 넘을 수 있다. 이는 안전성
  검사의 NaN/Inf 유계성과 별개이며, 실제 사용에서는 LEVEL로 헤드룸을 확보한다.

### 1.8 신호 구조와 기술 가정

```text
입력 형식: Mono / Stereo, 32-bit float
출력 형식: 입력과 동일
신호 처리 순서:
  1) 입력을 100 % 지연 정렬 드라이와 added 생성 경로로 분기
  2) 여기 대역 추출: LR4 하이패스 @ FOCUS + LR4 로우패스 @ 2×FOCUS (1옥타브)
  3) 채널 링크 엔벌로프로 adaptive 정규화 기준 생성
  4) 4x 오버샘플링
  5) IIR 올패스 4+4단 힐베르트 변환기로 해석신호 z = a + j·b 구성.
     `generatorDrive = 0.84`로 엔벌로프 정규화한 뒤 Re(z²) = a²−b²,
     Re(z³) = a³−3ab²를 생성하고 CLARITY로 두 차수의 배합을 모프.
  6) 다운샘플링 → LR4 잔류 하이패스 @ 2×FOCUS → 18 kHz 로우패스
  7) 보고 레이턴시만큼 지연된 드라이에서 최대 +6.5 dB 하이셸프를 계산하고
     `shelf(delayedDry) - delayedDry` delta만 추출. 코너는 min(3×FOCUS, 9 kHz).
  8) 같은 지연 드라이를 고정 8대역으로 분석해 주변보다 좁게 솟은 공진을 찾고, 해당 대역의
     셸프 delta만 직렬 보호 필터로 최대 25 % 완화. 마지막 16.97 kHz는 인접 로그 기울기를
     외삽해 보호한다. 스테레오 검출은 링크하되 오디오는 섞지 않음.
  9) BRIGHT로 보호된 셸프 delta의 양을 조절하고, 같은 `brightControl`에 `wetScale = 0.36`을
     선형으로 곱해 이전 생성기보다 약 20 dB 낮은 해석신호 배음을 보조
 10) WIDTH로 added 경로만 M/S 폭 조절 (0–200 %)
 11) 100 % 지연 정렬 드라이에 added를 합산
 12) LEVEL 트림
Dry/Wet 또는 병렬 구조: 지연 정렬 드라이는 모든 BRIGHT 값에서 100 % 유지한다. BRIGHT 0 %에서는
                          added가 0이므로 출력이 지연 드라이와 샘플 단위로 정확히 같다.
지원 채널 구성: Mono→Mono, Stereo→Stereo. adaptive 정규화 엔벌로프는 채널 링크.
레이턴시: juce::dsp::Oversampling의 정수 레이턴시를 `setLatencySamples()`로 보고하고,
          일반 처리와 호스트 bypass 모두 같은 지연을 유지한다. 최종 샘플 수는 최신 Harness
          출력으로 확인하며 허용 범위는 2 ms 이하다.
예상 CPU 등급: 낮음~중간 (4x OS 배음 경로 + added 셸프 + 고정 8대역 IIR detector/protector)
오버샘플링 필요 여부: 필수. 고역 대역에 비선형을 걸므로 오버샘플링 없이는 앨리어싱이
                      바로 fizz로 들린다.
잔류 기음 처리: 과거의 zero-lag 최소자승 투영은 OS 지연과 reference가 정렬되지 않아 제거했다.
헤드룸: 내부 리미터가 없다. 구조가 NaN/Inf를 억제해도 0 dBFS 초과를 보장하지 않으므로
        강한 설정은 LEVEL로 보정한다.
외부 파일·IR·모델 의존성: 없음
제3자 라이브러리와 라이선스: JUCE (juce::dsp::Oversampling 등) 외 없음
```
