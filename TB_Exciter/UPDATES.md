### 알려진 제한 사항

- VST3 Processor/Controller CID는 Release `moduleinfo.json`에서 확정했고 이후 변경 금지다.
  Processor `ABCDEF019182FAEB5462536454625863`, Controller `ABCDEF011234ABCD5462536454625863`.
- UI는 DSP 확인용 임시 화면이다. Factory 프리셋과 사용자 프리셋 Save/Load는 미구현.
- 최종 투명화 후보의 Release build, Harness·진단·batch validator 의미 게이트를 통과했다.
  통과 개수는 이 문서에 고정하지 않고 최신 Release 출력의 의미 게이트를 기준으로 한다.
  validator가 실제 버스 수를 assert하지 않는 경우 포맷 레벨 버스 검사는 별도로 보강한다.
- 지연 보상과 샘플레이트별 LUFS 계산을 적용한 최종 후보 A/B WAV 27개를 다시 렌더했다.
  **사람의 레벨 매칭 청감 A/B**는 아직 수행해야 한다.
- FOCUS 필터 계수의 실시간 heap 할당을 제거했고 64/2048 sample 자동화 출력은 일치했다.
  빠른 FOCUS 자동화의 클릭 여부는 청감으로도 확인한다.
- 내부 리미터가 없다. 공개 범위는 유한·유계여야 하지만 BRIGHT·WIDTH·LEVEL 극단 조합의
  무클리핑을 보장하지 않으므로 LEVEL로 헤드룸을 확보한다.
